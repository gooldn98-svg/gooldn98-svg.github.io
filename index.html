🔢 الوحدة الأولى: الأعداد المركبة

١-١ العدد المركب وصورته الجبرية

عجزت الأعداد الحقيقية عن إيجاد جذور تربيعية للأعداد السالبة، فظهرت الأعداد المركبة.

الصورة الجبرية: ع = أ + ب ت (حيث ت² = -١)
مثال: ضع ع = 3 + جذر(-16) بالصورة الجبرية ← الحل: 3 + 4ت

١-٢ جمع وطرح الأعداد المركبة

ع₁ ± ع₂ = (أ₁ ± أ₂) + (ب₁ ± ب₂)ت

١-٣ ضرب وقسمة الأعداد المركبة ومرافق العدد

مرافق ع = أ - بت | ع × عَ = أ² + ب²

١-٤ الصورة القطبية للعدد المركب والجذور

المعيار ر = جذر(أ² + ب²) | ع = ر(جتا هـ + ت جا هـ)

🔢 الوحدة الثانية: مبدأ العد ومبرهنة ذات الحدين

٢-١ مبدأ العد الأساسي

العدد الإجمالي للطرق للعمليات المتتالية = ن₁ × ن₂ × ...

٢-٢ التباديل والتوافيق

ل(ن، ر) = ن! / (ن - ر)! | ق(ن، ر) = ن! / [ر!(ن - ر)!]

٢-٣ مبرهنة ذات الحدين والحد العام

الحد العام: ح(ر+1) = ق(ن، ر) × س^(ن-ر) × ص^ر

🎲 الوحدة الثالثة: الاحتمالات

٣-١ المبرهنات الأساسية في الاحتمالات وفضاء العينة

ل(أ ∪ ب) = ل(أ) + ل(ب) - ل(أ ∩ ب)

٣-٢ الاحتمال الشرطي وقانون الضرب والحوادث المستقلة

ل(أ | ب) = ل(أ ∩ ب) / ل(ب)

📐 الوحدة الرابعة: القطوع المخروطية

٤-١ القطع المكافئ وعناصره ومعادلاته

ص² = 4جـ س (حيث البؤرة (جـ، 0))

٤-٢ القطع الناقص وعناصره ومعادلاته

(س² / أ²) + (ص² / ب²) = 1 (أ > ب)

٤-٣ القطع الزائد وعناصره ومعادلاته

(س² / أ²) - (ص² / ب²) = 1
